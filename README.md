# TribalSetu 🌉

> **Empowering Tribal Talent with Intelligent Digital Governance**

TribalSetu is an AI-enabled, unified digital scholarship and fellowship management platform designed for the **Ministry of Tribal Affairs (MoTA)**. It streamlines schemes such as the National Fellowship for Higher Education of ST Students (NFST) and National Overseas Scholarship (NOS) by replacing slow, manual document scrutiny with automated OCR intelligence, configurable eligibility workflows, and transparent merit-based selection.

---

## 🚀 Key Features

* **Configurable Scheme Engine:** Easily configure rules, eligibility criteria, and document requirements for different schemes without writing new code.
* **AI & OCR Document Intelligence:** Automated data extraction and validation for caste, income, marksheets, and university offer letters (with DigiLocker integration capability).
* **Automated Deficiency Management:** Flags specific document discrepancies and allows targeted re-uploads with real-time status alerts for students.
* **Explainable AI (XAI) Scoring:** Transparent merit list computation with human-in-the-loop validation for Ministry officials.
* **Interactive Dashboards:** Real-time analytics for MoTA administrators to track application pipelines, state-wise demographics, and fund disbursals.

---

## 🛠️ Tech Stack (Proposed)

* **Frontend:** React / Next.js, Tailwind CSS
* **Backend:** Node.js / FastAPI (Python)
* **AI & Document Processing:** Tesseract OCR / PaddleOCR, OpenCV
* **Database:** PostgreSQL / MongoDB

---

## 🎯 Target Schemes
* **NFST:** National Fellowship for Scheduled Tribe Students (M.Phil / Ph.D. in India)
* **NOS:** National Overseas Scholarship (Master's / Ph.D. abroad)
